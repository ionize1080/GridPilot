GridPilot 0.6.0 验证记录 — 2026-10-09
====================================

交付性质
--------
v0.6.0 正式 Release，按 Windows 10 + Excel 2010 标准版的接口和运行基线实现。
当前开发机是 Windows 11 系列（系统 build 26300）、Excel 16.0 64 位、.NET Framework 4.8.1。
当前没有 Windows 10 / Excel 2010 真机或虚拟机，不能宣称已完成该组合的兼容认证。
测试程序未带现代 Windows 清单时可能输出 NT 6.2；这不是实际系统版本，以上以系统为准。

已验证
------
• Release 构建成功，无警告、无错误，生成 PE x86 与 x64 两种 XLL。
• Core / UI / 宿主 DLL 都显式嵌入 XLL；以只含 XLL 的隔离目录进行64位加载测试。
• 基础与 UI 行为测试：中文、大小写、字面字符、正则、错误表达式、超时、取消、5000条
  快照搜索、模块命令、当前页面选择、隐藏页阻止跳转、快速改词、搜索期间禁用旧结果跳转、
  范围改变清空旧结果和空工作簿状态。
• 真实 Excel COM：枚举 Sheets（含图表页）、隐藏/VeryHidden 标识、图表跳转、Sheet 重命名、
  当前/所有工作簿范围、跨文件同名页面定位、删除页/关闭文件后拒绝陈旧请求、线程检查。
• 实际 x64 XLL 加载，调用导航命令创建原生任务面板，关闭自有 Excel 测试实例后进程正常退出。
• WPF 真实控件离屏渲染：340px 常规宽度、280px 窄宽度、144 DPI、正则结果、正则错误。
  PNG 来自实际控件和示例数据，不是 Excel 2010 的屏幕截图。

测试计数
--------
不带渲染的基础 + Excel 集成：169 项断言；默认配置启动。
带 UI 渲染的基础测试：140 项断言；无渲染基础测试 120 项。
两组包含重复基础检查，不能相加当作独立测试数。

v0.2 延续验证
-------------
• 配置文件往返、缺省字段、数值边界、全部偏好恢复、损坏回退及损坏原文备份。
• 只读文件保存失败、无效保存路径、不兼容未来配置版本保护、恢复默认值。
• 工作簿名自动/始终/从不显示，行高实际应用于 WPF 项，大字号和双行最小高度。
• 紧凑模式、设置页、跨工作簿结果及高 DPI/窄面板渲染。
• Excel 16 实际 CTP：默认右侧、宽度320；重新启动读取配置后左侧、宽度380。

• Excel 2010 上手动拖动停靠的记忆、设置保存和任务栏切换仍需目标机验收。

v0.3 新增验证
-------------
• 数字草稿不改配置；Enter/失焦提交、边界约束、非法输入保留旧值；滑块/输入框同步。
• 颜色简写归一化、非法颜色拒绝、实时资源更新、自定义颜色和提示开关跨启动保存。
• 原生宽度来源保护：观察到的宽度不生成几何写回；手动设置仍生成请求；异常后恢复保护状态。
• 宽度变化不再通知每条结果重新计算行高/间距；真正行高变化仍正确通知。
• 提示开关实际作用于 WPF 按钮；浅灰、深色、配色设置界面新增离屏渲染并人工查看。
• 深色启动配置在真实 Excel 16 加载，左侧380宽度恢复；默认右侧320也验证。
• 退出检查曾在 v0.2 与本版共同复现：任务面板卸载后存在待回收的 Office RCW，
  空白 Excel 或只加载 XLL 不打开面板则能退出。已补齐事件解绑，并在卸载后通过后台
  回收释放不可达对象；主线程保持可处理 COM 消息，不强制释放共享的 Office RCW。
  修复后默认/保存配置的两组88项断言均通过，测试实例实际退出。
• 集成测试跨工作簿跳转采用刷新后的目录，避免新建未保存工作簿时 CodeName 延迟初始化
  引发旧标识失效；旧标识拒绝机制仍保留。
• 原生拖动的实际闪烁/顺滑度没有在 Excel 2010 上测量，不以纯逻辑测试或 PNG 宣称已消除。

修复记录
--------
1. 图表的 Chart.Type 是图表类型，不等同 Worksheet.Type；已改用 COM 类型信息区分。
2. 新建未保存工作簿的 CodeName 可能为空；空值时采用 COM 身份，支持重命名后导航。
3. 为插件添加退出/断开/卸载的幂等清理。集成测试显式释放自己拥有的 Excel 应用 RCW，
   解决自动化客户端持有对象导致的进程退出误报；生产代码不强制释放共享 Office RCW。
4. 查询更新期间不允许 Enter 激活旧结果；队列失败会反馈/记录而不把异常冒泡到 Excel UI。

尚未验证/性能边界

• x86 XLL 已构建并检查架构，尚未在32位 Excel中实际加载。
• Excel 2010 的任务栏文件切换、浮动停靠、关闭与重新加载：待目标机人工验证。
• 高DPI已检查控件渲染及 Excel16 的200%实际窗口；Office 2010 跨显示器缩放仍需人工测试。
• 5000条测试只针对脱离Excel的数据搜索，不代表5000张真实Sheet扫描的性能。
• Windows 10 1507/1511 没有自带 .NET 4.6.2，不属于本次无需补装运行时的基线。

%TEMP%\GridPilot-<进程号>.log。无需提供业务工作簿内容即可先定位加载和生命周期问题。

覆盖层验证：

- 实际F2进入单元格编辑、Esc退出：高亮暂停/恢复，没有提交修改。

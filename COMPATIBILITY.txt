GridPilot v1.0.0 目标机验收
==========================

适用：64位 Windows 10/11，已安装 Excel 与 .NET Framework 4.6.2 或更高版本。
主便携包不需要 WebView2、Chrome、Node.js 或安装器，不要求管理员权限。
本版未在 Win10 21H1 + Excel 2010 真机上验收，也未在32位 Excel 实机加载。

1. 解压主便携包至用户可读写目录，不要只复制 XLL。
2. 按 Excel 位数选择 GridPilot-x86.xll 或 GridPilot-x64.xll。
3. 兼容性测试包是独立可执行测试集，按 Excel 位数进入 x86 或 x64 文件夹，
   双击 GridPilot-Compatibility.exe。测试会创建自己的 Excel 实例与合成文件。
   运行时不要操作 Excel，完成后查看同目录 results-时间 中的 summary.txt 与日志。
   所有测试均针对合成数据，不会扫描个人文件。测试不安装组件或改安全策略。
4. 自动测试通过后，仍需使用主包人工验收以下实际宿主操作：
   - 第一次打开数据脱敏/总设置，在没有 WebView2 与网络的环境下可显示。
   - 导航跳转后直接滚轮滚动、方向键移动，不需要切换其他工作簿恢复。
   - Excel 2010 MDI 中多文件切换、最大化/还原、缩放与冻结窗格。
   - 合并和多行表头建议正确，检查数据起始行；预览后保存新副本。
   - 保留格式开/关均可导出，源文件未变化；新文件重新打开正常。
   - 前后缀及人名模式修改后，同一关联字段同步；取消另存为保留预览。
   - 大表处理显示进度，取消或关闭后不生成未完成文件；完成后核对全部数据。
   - 前方行高列宽变化后聚焦跟随，涟漪覆盖行头列头，反复点击后正常结束。
   - 总设置切换图标配色、调涟漪时长与强度，关闭复杂窗口后键盘返回 Excel。
   - 关闭最后一个复杂窗口后，无残留 GridPilot 浏览器窗口；退出 Excel正常。

测试包本身不包含 Chromium，界面人工验收请使用主便携包。
所有套件通过表示这些已执行用例通过，不表示所有业务公式和工作簿兼容。
条件格式规则及其动态显示效果、图表、宏、批注等不随脱敏输出复制。

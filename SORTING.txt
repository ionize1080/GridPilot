GridPilot 1.5.1 自定义排序

开启：设置 → 功能开关 → 自定义排序 → 保存。导航与聚焦常驻，其余工具默认关闭。
可单独关闭“在 Excel 原生右键菜单显示自定义排序”；Ribbon 入口继续保留。
右键入口属于单元格和 Excel 表格原生菜单，没有第二个弹出菜单。筛选箭头下拉菜单不作扩展。

快速开始：选择“客户一处、客户二处…”示例，再点“套用示例”，会填入 .*?[中文数字] 并预览。下方“自定义顺序”可留空；仅当需要 阶段=准备,实施,验收 这样的自定义顺序时展开填写。预览会显示匹配和未匹配数量。

操作：在数据中选一个单元格，打开排序，确认显示的完整区域和依据列、表头选项，选择预设或输入规则，预览后应用。排序使用整个连续数据区域 / 筛选区域 / Excel 表格，包含隐藏行，不只移动选中的那一列。不自动保存工作簿。对话框“恢复原序”或开启后的 Ribbon“撤销上次操作”可撤销；后续编辑会使撤销失效。

规则每行一条，优先匹配靠前的规则；从名称开头匹配，可用 .*? 匹配前缀。
例如：
(国际)[中文数字]
(业务)[中文数字]

国际二部 → 国际十一部 → 国际一百零一部 → 业务一部 → 业务十部。
降序只反转组内序列，规则优先级保持不变。相同键值保留原序；未匹配项置后并保留原序。
[大中小微][中文数字] 可以形成两层组合；大一、大十、中二、小一、微一。

自定义序列区每行“名称=项目1,项目2,项目3”，如：
级别=特大,大型,中型,小型,微型
阶段=准备,实施,验收
规则中用 [级别][中文数字] 或 [阶段]。项目作为文字匹配，不解释正则；较长项目优先匹配，排序仍按定义顺序。
规则中的其他部分是 .NET 正则，如 (国际|海外)[中文数字]、[A-Z][中文数字]。
每个序列标记必须参与匹配；可选分支应拆成多行规则。最多 32 条规则，每条 512 字符。匹配有超时保护。
中文数字为任意精度整数，支持十百千万亿兆京垓秭穰沟涧正载、财务大写和两/〇，不使用仅到一百的枚举表。连续数字写法如二〇二四也能排序。
名称自然排序忽略自定义规则，按中文区域文字和阿拉伯数字分段比较，表2排在表10之前。

导航“工作表排序”作用于选中页面所属工作簿的全部标签，包括隐藏页与图表页，不受导航搜索过滤影响；预览后改变实际标签顺序。隐藏/深度隐藏状态保留。工作簿结构保护时拒绝操作。
导航右键“原地重命名”或列表获得键盘焦点后 F2；Enter 保存，Esc 取消。非法或重复名称会提示。布局设置中的“鼠标悬停高亮”可选择颜色。

边界：一次最多 200,000 条记录、2,000,000 个单元格。排序区域右侧需留出空白列作为临时排序键，完成后清理。合并表头保留；同一行内的横向合并可排序，合并结构随记录恢复。数据区跨多行合并、数组 / 溢出公式、数据透视表、受保护或只读工作簿拒绝逐行排序。Excel 表格标题行固定保留，汇总行排除在数据之外。排序窗口打开期间，先完成或关闭窗口再操作 Excel；预览后源数据改变时仍会拒绝应用。

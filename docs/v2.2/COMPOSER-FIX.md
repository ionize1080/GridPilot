# 输入区布局修正

2026-11-17，针对 Windows 高 DPI Excel 侧栏中工作区、上下文与模型按钮挤在同一行的问题。

- 工作区与 Excel 上下文独立一行；附件、工具与模型选择保留原生控件，窄侧栏允许按组换行。
- 模型名称显示区域扩大；Excel 工具菜单靠右展开，避免越出侧栏。
- 移除底部 AI 内容准确性提示及占位；减少输入区留白，单行输入自动随多行草稿增长。
- 切换侧栏／独立窗口后不长期保留额外确认条。
- 工作区触发按钮使用原生 Popover 关联，修复再次点击时先关闭又重新打开的问题。

验证：生产 Chatbox 输入区通过 320、360、440、480、1100 像素及 150%／200% 缩放检查，覆盖控件边界、按钮重叠、菜单、工作区开关、多行输入和草稿保留。通过桌面操作在本机 Excel 的约 440、420、320 像素侧栏查看了实际显示。

从 `D:\APP\GridPilot` 安装文件启动的隔离真实 Excel 测试通过 8 次侧栏／独立窗口切换，并检查实际窗口归属、输入区分行、提示移除、草稿保留与当前单元格不变。测试使用合成工作簿及独立模型配置，没有发送用户数据。

相关测试：`tests/composer-layout.cjs`、`tests/browser-ai.cjs` 的 `GRIDPILOT_LAYOUT_TEST=1` 分支，以及 `tests/native-ai-switch.cjs`。

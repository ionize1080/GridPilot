## 界面与设计

采用语义颜色与深浅两套调色：中性背景、绿色交互强调、文字/图标同时表达状态。浮层提供清晰内容面，支持减少透明度、减少动态效果、增强对比度与键盘焦点。设计参考 [Apple Color](https://developer.apple.com/design/human-interface-guidelines/color) 和 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)，不捆绑 Apple 字体或图像。

## 边界

- 本次模型端使用本地模拟服务，实际调用生产 MCP 和解析组件；未使用付费模型 API，也不把模拟回答当作模型识别准确率测试。
- Win10、Excel 2010、32 位 Excel 宿主尚未在目标机验收；x86 XLL 成功构建不等同于实际 32 位宿主通过。
- 95 种扩展名不等于支持每种专有内部对象；扫描页需视觉模型，XLSB 仅缓存值、无公式文本，Office 版式需 PDF 验证。邮件附件只列目录，需要单独添加。
- 工作区读取可持续分页，但模型上下文和单次解析仍有预算；遇到继续标识或错误不能宣称已完整读取。
- 清空只撤销引用，不删除源文件、底稿磁盘文件或已发送历史内容。撤销仅针对最近一次有内容的清空；新增资料保留。工作区底稿不计入 Excel 恢复快照预算。

构建/测试入口见 [BUILD](../development/BUILD.md)。最终压缩包逐项校验与发布附件 SHA-256 以 Release 附带清单为准。

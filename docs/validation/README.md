## 环境

Windows 11、Excel 16 x64、.NET Framework 4.6.2 目标、Electron 44.7.0、Chatbox 1.20.3。工作簿和附件使用合成数据，真实 API 密钥来自仓库外文件。x86 测试进程连接本机 x64 Excel，不能据此证明 32 位 Excel 宿主兼容。

## 10 项 MCP 工具矩阵

| 工具 | 真实 API 验证内容 |

| excel_read | 模型调用并返回实际单元格数据 |

## 前一版本与历史基线

v1.9 的完整构建原有各组回归共 751 项断言通过；当时新增 AI 实际 Excel 回归各 91 项。还覆盖六类图表、五种透视汇总、手工冲突、全部支持格式字段、源变化及取消读取。这些是当时执行记录，不能把 751、91 和当前 106 相加后称为当前“全覆盖”。

非 AI 功能的历史验证入口：[v1.6 排序等验证](../v1.6/VALIDATION.md)、[早期累计记录](VALIDATION.txt)、[v1.0 审查修复](../v1.0/REVIEW-RESOLUTION.md)。测试入口与重跑方式见 [构建与测试](../development/BUILD.md)。

## 尚未完成与不能保证的内容

- Win10 / Excel 2010 32 位尚未实机验收；按 [目标机清单](../guides/COMPATIBILITY.md) 继续验证。
- 计算机操作工具不能独立绑定 Excel 所有的 Chromium 窗口，停靠后的第二次物理键盘输入未计为人工通过；已有窗口样式、草稿与渲染器输入验证不替代这一项。
- 10 项工具都执行过不等于覆盖任意公式、全部 Excel 元数据或所有业务工作簿。
- 本地备份与冲突检测降低恢复风险，不能保证任意宏、副作用、磁盘／进程故障下绝对无损；恢复边界见 [AI 指南](../guides/AI.md#批准与恢复)。

## 新能力与额外发现

- 词频与多样性门槛推断项目、企业、人名、编号前后缀；全列分布抽样而非只读开头，用户可改前后缀、位数和人名模式，同一关联域同步。
- 删除固定 50 万／200 万格门槛；自适应稀疏扫描、每块最多 32768 格、全范围坐标、真实有内容行列数。超预算停止，绝不静默截断。
- 样式按行流式合并，减少大型 XML 常驻对象；提交前全量复核源，导出后重算并重开验证。
- 修复另存为取消丢失预览、取消按钮不可达、关联字段显示与数据不同步。
- 修复动画定时器跨线程重启失效；事件绘制统一到覆盖层所属线程，动画帧只使用已捕获几何。
- 涟漪加入衰减波峰与波谷、曲面层次、更远起始位置和行列头传播；依据绘制开销调整动画时钟。

## 明确边界

完整是指所选规则覆盖整个已捕获工作簿并全量校验，并不保证所有 Excel 公式或对象都支持。公式采用保守白名单，单范围最多 800 万格并有总计算预算；x64/x86 有不同内存保护。图表、宏、批注、条件格式规则等不复制到干净输出。自动建议仍需用户核对，尤其是可识别身份的前后缀。

跨期加密映射、书签导航及独立隐私体检属于可选演进建议，未包含在本版。测试结果与兼容性范围详见仓库根目录 VALIDATION.txt。

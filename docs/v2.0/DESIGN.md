# v2.0 设计记录

批准按钮独立放在上下文范围旁：手动为盾牌，自动为红色闪电、浅红底及细边框。使用 aria switch、键盘焦点及说明文字，颜色以外还有形状差异。更多菜单代理原生联网搜索按钮，保留其提供方／会话状态，避免复制联网实现。

以 excel_help／excel_operation 容纳高级目录，保持每轮工具入口数为 12。参数、状态和风险由 Excel 宿主再次检查；模型不能提交审批或还原命令。危险 VBA 必须单项确认，不能被普通批量应用顺带批准。

历史快照采用内容寻址和不可变版本清单。原生 Excel 输出优先保证还原完整性，去重针对存储；不声称 SaveCopyAs 具有瞬时数据库快照性能。恢复为独立副本，避免复制工作表导致 VBA／图表／缓存丢失，保留正在编辑的原工作簿。

Excel 2010 边框处理通过客户区坐标与裁切消除残留非客户区；继续使用 owned top-level HWND，避免 Excel 吞掉 Chromium 键盘输入。真实 2010 环境尚待验收。

# GridPilot v0.7.0 — 原样复制

> 本页记录该次发布，保留原始功能与验证结论。[最新使用文档](../README.md) · [全部版本](README.md)

新增两个独立按钮：**原样复制·内部公式**、**原样复制·仅数值**。复制到新建、未保存的工作簿，保留原单元格位置与可配置的排版。

- 内部公式版保留可确认依赖全部位于复制范围内的普通 A1 公式，其余默认转为当前计算值；可改为遇到不能保留的公式就停止。
- 仅数值版把全部公式转为当前值，保留普通文本、数值、布尔值与错误值。
- 细项统一放在 **设置 → 原样复制**：范围、可见单元格、字体/填充/边框、数字格式、行高列宽、隐藏、合并、传统批注、视图、条件格式、公式策略和数量上限。
- 批量读写、公式分块、连续行列布局处理；修正 Excel 原生复制筛选区域时压缩隐藏行的问题。状态栏显示阶段，支持 Esc 取消；出错时关闭未完成结果。

本机 12 万单元格、2 万条公式的合成样例，内部公式约 **0.9 秒**，仅数值约 **0.6 秒**。大量条件格式与零散区域可能更慢。

## 使用与边界

下载 `GridPilot-0.7.0-portable.zip`，退出 Excel 后解压升级，保留原 `GridPilot.navigation.json` 与 `GridPilot.tools.json`。按 **Excel 位数**选择一个 XLL：32 位用 `GridPilot-x86.xll`，64 位用 `GridPilot-x64.xll`。

这是单元格复制，不是整个工作簿克隆。默认将条件格式固定为静态外观；数据条、图标集需选择“仅基础格式”。跨表/跨簿、名称、结构化引用、动态引用、数组与未知函数按策略转值或停止。图片、图表、形状、数据验证、超链接、打印设置和冻结窗格不复制。详细设置和边界见包内 `COPYING.txt`。

发布包包含说明、校验文件及双位数 XLL，另提供独立 XLL 和源码包。XLL 未进行发布者数字签名，沿用原 Office 信任策略。

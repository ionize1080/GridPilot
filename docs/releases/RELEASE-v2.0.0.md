# GridPilot v2.0.0 — Excel 操作与多版本快照

2026-10-22

输入栏现在可以直接切换手动／自动批准：手动是盾牌，自动是红色闪电和浅红底。联网搜索收进更多设置。含网络、Shell 或动态执行风险的 VBA 始终要求逐项手动批准，普通批量应用不会顺带批准。

## 新增与增强

- 12 个精简 MCP 入口，79 个按需发现的高级操作；工作簿、工作表、单元格范围、格式、验证、条件格式、表格、名称、批注、图片、迷你图、CSV、VBA 读写等。
- 增强原生透视表：字段增减和重排、11 种汇总、筛选、排序、分组、计算字段／项、显示值方式、布局、切片器；日期时间线要求 Excel 2013+。
- 73 种 Excel 2010 图表，支持轴、绘图区、曲线、点、字体、颜色、图例、标签、趋势线、误差线及次轴组合编辑。属性适用范围遵循 Excel 原生对象模型。
- 常用插件接入：批量重命名与预览、自定义多级排序、工作表排序、转文本／数值、原样复制、离线分词、简易脱敏。
- 多版本完整快照：按部件和内容压缩去重，校验恢复；打开历史完整副本，保留原工作簿及未保存编辑，支持删除工作表后的恢复。
- 侧栏按客户区定位并裁切残留边框，保留窗口／侧栏切换和输入焦点。
- MCP 按需说明、Resource／Prompt、只读策略和工具过滤，避免每轮携带整份操作目录。

## 验证与限制

已在 Windows 11 / Excel 16 x64 执行实际 Excel、原生 Chatbox、真实 DeepSeek API 和窗口切换测试。73 种图表逐一创建验证；xlsx／xlsm／xlsb／xls 快照与宏审批验证通过。详见 [验证记录](../v2.0/VALIDATION.md)。

Excel 2010 黑边修复已实现，但本机没有该版本，仍需目标机实测，不能宣称已完全消除。完整历史恢复打开独立副本；SaveCopyAs 仍有整簿保存成本，目前不自动清理历史。VBA 风险检测是静态审核门槛，不是任意混淆代码的安全证明；不执行宏、不更改信任中心。

本次优先接入常用插件，数据库、监管核对及智能关系脱敏等复杂流程仍使用原界面；不将这些现有界面宣称为已经完成的 MCP 能力。逐步公式求值和任意 COM 反射不提供。Excel MCP 不含网络数据操作或 HTTP/SSE 服务。

## 安装

提供 portable 完整包与 clean 精简包，均含 x86/x64 XLL 和必需运行时。退出 Excel 后完整解压，按 Excel 位数选择加载项；不能只替换 XLL。升级保留配置和旧版完整备份。真实测试密钥、对话配置与测试工作簿不随包发布。

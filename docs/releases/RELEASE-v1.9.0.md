# GridPilot v1.9.0 — 安心切换，轻巧工作

> 本页记录该次发布，保留原始功能与验证结论。[最新使用文档](../README.md) · [全部版本](README.md)

本版改进 Excel AI 助手的批准、恢复、侧栏和大表体验，并加入原生数据透视表。

- 可选自动批准，默认关闭；写入前后自动保存完整工作簿副本。界面一键切换变更前/后，检测手工编辑冲突并停止覆盖。
- 侧栏关闭非客户区边框和阴影，去掉内部重复窗口按钮；增加独立窗口/侧栏切换小按钮。
- 大表分块准备、实时格数细进度条与取消；读取期间检测到编辑则取消发送。
- 10 个 MCP 工具：读取、查找、统计、结构检查、单格/批量公式、批量内容、格式、原生图表和透视表。等待工具就绪再发送，提供精简公式调用指导。
- 透视表在新工作表生成，支持行列分组和五种汇总方式；支持冲突检查及前后恢复，输出上限 100,000 格。
- 精简中文范围标签、圆角下拉菜单、新 AI 图标及辅助技术可访问性修复。

真实 DeepSeek API 已完成原生 Chatbox → MCP → 实际 Excel 的 10 个工具全链路测试；测试数据为合成数据，密钥不包含在代码或发布包中。

完整备份位于用户本地应用数据目录 GridPilot/Recovery，菜单可打开；关闭助手后仍保留，需自行保管和清理。界面可切换最新检查点，完整备份用于关闭助手后的手工恢复。自动批准遇到错误、切换会话或恢复时关闭。重叠格式与不支持的目标会停止写入。

本机验证环境为 Windows 11 / Excel 16 x64；Win10 / Excel 2010 32 位尚未实机验收。两个 Excel 位数的 XLL 均随包提供。便携包要求 64 位 Windows 10/11、.NET Framework 4.6.2+，无需安装 Node.js 或 WebView2。

升级前退出 Excel，完整解压；保留 GridPilot.navigation.json 和 GridPilot.tools.json。不要混用新旧版本文件。

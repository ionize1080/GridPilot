# GridPilot v2.1.0：自动上下文、快照预算与新版 Office

发布日期：2026-10-22。

## 主要变化

- **快照预算**：默认 500 MB，最低 100 MB，在总设置 → AI 助手调整。按压缩去重后的清单与数据块实际占用计算，超额先删最旧版本，再回收没有引用的块。单个快照超过预算会明确报错。手动恢复/导出副本和旧版独立备份不在自动清理范围内。
- **简洁菜单**：解释公式、生成内容、分析数据、手动公式草稿可分别在总设置关闭；保留正常 AI 对话和工具能力。
- **默认自动模式**：先列出当前 Excel 进程已打开的工作簿目录，再按任务读取整本、指定工作表或区域。隐藏表和 VBA 纳入可发现范围；“所有工作簿”模式要求逐本核对并说明遗漏。新增 excel_context，读取有进度和取消，完整本地统计不依赖样本。不会读取未打开的磁盘工作簿或其他 Excel 进程。
- **自动批准二次确认**：原生确认框说明修改、删除、VBA、授权有效期和快照清理风险，默认选择“否”。授权仍绑定具体工作簿；危险 VBA 始终逐项手动批准。
- **新版 Office 工具**：共 13 个 MCP 入口、99 项按需发现操作。新增动态数组 Formula2/溢出、线程批注与回复、Power Query 定义、连接目录、数据模型概况、切片器筛选/时间线、表格调整，以及现代图表。按主版本与实际接口探测启用；具体图表、数据形状和受保护对象交由原生 Excel 校验。

Power Query 工具仅处理定义，不自动刷新外部来源。地图图表可能使用 Office 在线地图服务。VBA 工具不运行宏，也不修改信任中心。

## 验证

完整构建及基础回归通过；实际 Excel AI 106 项、高级操作 48 项、新版专项 27 项、原生图表矩阵 73 项、四种文件格式及 VBA 26 项断言通过。新版专项覆盖预算淘汰与去重恢复、旧设置迁移、跨工作簿同名表、隐藏表、冻结数据、关闭目标拒绝、授权隔离、动态数组、查询、批注、表格与切片器、7 类现代图表。

真实 DeepSeek API 完成跨工作簿汇总、隐藏调整和 VBA 系数核对，以及新版工具写入；原生 Chatbox → 真实模型 → MCP → 实际 Excel 链路另行通过，覆盖公式、格式、图表、透视表、前后恢复和超过 20 万格读取。原生确认框取消/确认/默认“否”及 8 次窗口切换通过。

详细环境、测试范围和已知限制见 [验证记录](../v2.1/VALIDATION.md)。已测 Windows 11 / Excel 16 x64（Build 20430）；**Win10 / Excel 2010 32 位仍未实机验收**。旧版功能保留，不把 x86 构建等同于旧版 Office 实测。

## 下载与升级

Release 提供完整便携包、精简包及 SHA256SUMS.txt。两种包都保留必需运行时、字典、Chatbox 和第三方许可；精简包不附额外文档。完整解压，按 Excel 位数选择 x86/x64 XLL，勿混用旧 DLL。

升级前关闭 Excel 和助手，备份旧目录及设置。保留 GridPilot.navigation.json、GridPilot.tools.json 和独立 Chatbox 用户配置。旧设置自动补齐 500 MB 预算和四个快捷入口默认值；已有功能开关不变。第一次打开新版助手会按预算清理历史，请提前导出需要长期保留的版本。

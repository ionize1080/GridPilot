# GridPilot v1.7.0 — Chatbox Excel AI 助手

集成官方 Chatbox **1.20.3**，固定版本并保留原生会话、模型、API、代理、MCP、外观、快捷键和数据管理设置入口。默认打开 Excel 右侧栏，也可在 GridPilot 设置 → AI 助手改为独立窗口；关闭助手后重新打开生效。

## 使用流程

1. 完整解压便携包，按 Excel 位数加载 x86 或 x64 XLL，点击 Ribbon 的 AI 助手。
2. 在 Chatbox 原生设置配置模型；完整查找和统计选支持工具调用的模型，保持 GridPilot Excel MCP 启用。
3. 选择选区、当前 Sheet、当前 Workbook 或不附加数据，再输入问题。可直接使用“解释公式、生成公式、查找数据、统计数据”提示。
4. 生成公式先显示目标、原内容与公式，点击“应用公式”才写入；可定位目标和撤销最近一次 AI 公式。

## 数据范围与保护

- 每次发送冻结上下文，已有建议绑定原工作簿；切换工作簿不会误写新工作簿，原工作簿关闭后失效。
- 最多扫描 200,000 格，超过整体拒绝；120 格样本明确标注，完整查找/统计通过原生 MCP 工具完成，按需读取每页 200 格。
- Workbook 仅含可见普通工作表；范围内隐藏行列包括在内。Excel 错误值不计入数值统计。
- 公式应用前再次检查目标，拒绝覆盖后续修改；保护、只读、合并、数组公式和表格计算列拒绝写入。当前支持单格普通公式，不支持动态数组、结构化引用及外部链接。
- Chatbox 原始模型设置保持原生入口；自动升级被固定版本规则禁用。模型服务的账号、密钥与费用由用户配置。

## 验证与兼容

在 Windows 11 / Excel 16 x64 验证真实 Excel 上下文、统计、预览/写入/撤销及两种窗口宿主；完整原生对话使用本地模拟模型验证工具往返，不包含付费云模型准确率评测。原有构建回归通过。Win10/Excel 2010/32 位 Excel 未实机验证。

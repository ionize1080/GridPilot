# GridPilot v1.9.1 — 连续批准，清晰应用

- 修复工具菜单开启自动批准后仍停留：操作后、点击外部、聚焦输入框或按 Esc 自动收起。
- 新增工作簿级自动批准：跨多轮对话、会话切换和前后快照切换保持有效。其他工作簿不继承授权；关闭工作簿或助手后失效。也可选择仅本次对话。
- 批量应用按建议生成顺序合并重叠单元格和格式属性，保留非重叠部分，过期建议不拖住整批；增加清空入口，单项丢弃也会同步清理后台。
- 应用中使用高对比按钮和明确状态，成功/失败反馈更容易辨认。
- 加固侧栏/独立窗口转换：复用窗格、按当前 Excel 窗口重新绑定、恢复正常窗口尺寸、避免重复点击。

完整备份、写入前冲突检查和整批回滚继续生效。需要开始新恢复点时保留此前的完整备份；界面只切换最新恢复点。工作簿自动批准遇到错误仍保留授权，但失败操作不会绕过检查继续写入。

真实 DeepSeek API 的 10 项 MCP 工具测试通过，实际 Excel 回归在 x64/x86 测试进程分别通过 106 项。x86 进程连接本机 x64 Excel，不能代替 Excel 2010 32 位实机验收。

# GridPilot v0.9.0 — 便携 Chromium 界面与智能脱敏

> 本页记录该次发布，保留原始功能与验证结论。[最新使用文档](../README.md) · [全部版本](README.md)

复杂界面改为独立的便携 Chromium 窗口：脱敏按「字段建议 → 预览 → 另存副本」完成，总设置按类别组织。无需安装 WebView2、Chrome、Node.js 或浏览器运行时，完整解压后即可使用。浏览器仅在打开复杂窗口时启动，关闭即退出；导航继续使用原生任务面板。

- 修复格式空白撑大 UsedRange 导致的数量误报；按实际有内容单元格计数，分块读取，稀疏区域按内容遍历。
- 识别标题下方的表头、合并表头和多行表头，允许逐列修正数据起始行。
- 按字段语义与重复值建议跨表共享映射；忽略「— / 无 / 合计」等占位文本。可选同步替换备注等其他位置出现的相同原文，预览列出变更。
- 默认保留基础字体、颜色、边框、数字格式、行高列宽、隐藏行列及合并布局；可在窗口或设置中关闭。结果继续排除条件格式规则、批注、图片、图表、宏、连接及定义名称。
- 聚焦增加四向涟漪，可调时长、宽度、强度；复用覆盖层位图，不写入单元格格式。系统关闭动画、高对比度或远程桌面时停用动画。
- Ribbon 图标使用统一线宽和高质量缩放，提供青瓷、晴蓝、石墨三套配色，可立即切换。
- 导航跳转后把焦点交还活动工作表，避免键盘和滚轮停留在导航控件。无全局快捷键或全局鼠标钩子。
- XLL 与 DLL、词典和 Chromium 拆分；聚焦与导航事件延后到首次使用。

## 下载和升级

下载完整 `GridPilot-0.9.0-portable-win-x64.zip`。包内同时包含 32 位和 64 位 Excel 的 XLL：按 **Excel 位数**选择。包内 Chromium 是 Windows x64 程序，因此本便携包要求 **64 位 Windows**；32 位 Excel 运行在 64 位 Windows 上可以使用。

退出 Excel 后解压到新的目录，保留旧目录备份；将已有 `GridPilot.navigation.json` 与 `GridPilot.tools.json` 复制到新目录。一次只加载一个版本。**不能只复制 XLL**，同目录 DLL、App、Browser、Resources 都是运行所需文件。

## 验证和兼容性

本机测试使用 Windows 11、Excel 16.0 x64，.NET Framework 4.6.2 构建基线。已覆盖原有功能回归、真实文件脱敏后重开、格式保留、跨表一致性、实际 Chromium 界面与进程退出。公开测试样本来自 Apache POI，宏始终禁用；不会发布用户样本或数据。

**目标 Win10 21H1 + Excel 2010 尚无实机测试环境，不能据本机结果声称已经验收。** x86 逻辑测试不等于 32 位 Excel 实机测试。请用附带兼容性检查包完成目标机验收，尤其是导航后滚轮、MDI 多文件切换、缩放和禁安装策略下的可执行程序许可。

性能仍有一项已知边界：连续自动化导出中偶发约 60 秒的 Office COM 等待，正常小文件约 2 秒；文件正确性检查通过，但尚未彻底消除该尾延迟。

支持的脱敏公式仍有白名单，无法保持关系的公式会停止导出。金额和日期默认不自动选择。保留的是基础格式，条件格式显示效果、主题自定义信息与其他非单元格对象不保证完整复现；交付前请检查保留字段和格式中的文字。数值编号若已被 Excel 丢失前导零或精度，不会猜测恢复。

# GridPilot v2.2.0 — 参考工作区与完整分页读取

2026-11-17

- **会话工作区**：文件、真实文件夹和虚拟文件夹混合管理，支持拖放、多选、重命名及嵌套；首次发送与重新打开会话保持资料一致。
- **一键清空 / 撤销清空**：只清空引用，不删除源文件或底稿文件。撤销恢复原结构并保留新添加资料；记录可跨助手重启保留，旧读取标识在清空后失效。
- **Excel 底稿**：分析副本可直接在当前 Excel 实例打开，保留原工作簿未保存的编辑，批准权限保持隔离。
- **12 个新增 MCP 工具**：目录、递归查找、结构、分页全文、批量片段、图片/PDF、离线计算与原生 Excel 分析副本。长单元格支持读到末尾，图片正确传给视觉模型，流式工具名和参数支持拆分增量。
- **95 种扩展名**：新增 XLSB、Office 模板、OpenDocument 模板/平面文件、邮件/MHTML、更多图片、数据及代码文本。
- **界面更新**：中性底色、低饱和绿色强调、柔和浮层与统一圆角；深浅色、320 像素窄侧栏、键盘焦点和增强对比度适配。

完整解压便携包，保留新增的 `Python/`、`bridge/` 与原有运行组件。无需用户另装 Python。升级前关闭旧版 Excel 加载项，不同时加载两份 XLL。工作区配置保存在用户目录，独立于发布目录。

实际验收环境：Windows 11 / Excel 16 x64；模型端使用本地模拟服务验证真实 Chatbox 与 stdio MCP 链路，未调用付费模型 API。Win10 / Excel 2010 / 32 位 Excel 宿主仍需目标机验收。扫描页需要视觉模型；XLSB 读取缓存值、不提供公式文本；复杂 Office 版式请导出 PDF 查看。

# GridPilot v2.2.1 — 更舒展的 Excel AI 输入区

2026-11-17

- 工作区与 Excel 上下文独立一行，附件、工具和模型选择分组排列；窄侧栏自动按组换行，不再相互挤压。
- 扩大模型名称显示区域，工具菜单靠右展开，避免越出侧栏。
- 删除底部“AI 生成的内容可能不准确…”提示及占位，收紧上下留白；输入框从单行开始，随多行草稿自动增高。
- 侧栏／独立窗口切换后不再长期保留额外确认条。
- 修复重复点击工作区按钮时弹层先关闭又重新打开的问题。

保留 v2.2.0 的参考工作区、95 种扩展名、12 个工作区 MCP 工具、清空／撤销及 Excel 分析底稿能力。

已验证生产输入区 320–1100 像素及 100%／150%／200% 缩放，包含控件重叠、菜单边界、工作区开关和多行草稿。真实 Excel 测试覆盖 8 次侧栏／独立窗口切换、草稿保留和当前单元格保护。实际验收环境为 Windows 11 / Excel 16 x64；旧版 Office 与 32 位 Excel 宿主仍需目标机验证。

升级前关闭 Excel 和助手，完整解压发布包，保留现有 GridPilot JSON 配置及独立用户数据目录。完整便携包附指南，精简包保留全部运行组件和许可证；两者均含 Python，无需另行安装。

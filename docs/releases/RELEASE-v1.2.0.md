# GridPilot v1.2.0 — 简易选区脱敏

> 本页记录该次发布，保留原始功能与验证结论。[最新使用文档](../README.md) · [全部版本](README.md)

新增独立“简易脱敏”入口，支持 Range、整行整列和不连续选区：

- 固定中文拼音首字母、26 个非直译英文字母汉字映射、数字置换与特殊字符编码。
- 首尾交换（自定义长度与快捷按钮）、倒序、自定义 .NET 正则查找替换。
- 数值和数字文本加减乘除；所有方式可加前后缀。
- 分页预览、全结果搜索、逐格跳过、取消、复制和 XLSX 导出。
- 原表写回需备份确认，检测过期单元格并跳过，支持撤销。
- 单独导出含原文的还原记录 JSON。拼音首字母本身不可逆，固定规则不等于加密。

跳过的原文不会混入复制/导出结果。导出为文本值；不复制原样式。支持最多 10 万个有内容单元格；详细边界见 SIMPLE-MASKING.txt。

包含 v1.1 的报表数据库与工作表管理功能，代码同步至 main。

使用完整便携包或清洁便携包并完整解压；按 Excel 位数选择 x86/x64 XLL。升级前退出 Excel，保留设置文件。系统要求 64 位 Windows 10/11 和 .NET Framework 4.6.2+。

验证记录见 VALIDATION.txt：核心规则、真实 Excel COM、浏览器界面与回归测试。Win10 + Excel 2010、32 位 Excel 尚未实机验收。

# GridPilot v1.3.0 — 简易脱敏智能表头识别

简易脱敏默认识别并保留表头，避免将报表字段与数据一起替换。可勾选“表头也脱敏”，或手动指定工作表行号（例如 `4-5`、`2,8-9`），也可关闭识别。

- 正式 Excel 表头优先；普通区域综合字段名称、下方记录、列覆盖、数字格式、加粗及横向/纵向合并结构判断，支持多层和重复表头。
- 标题、统计时间、导出者等前置信息与字段区分。默认参与脱敏，另有“同时保留”选项；保留导出者可能包含敏感信息。
- 识别读取工作表上下文，选择某列或仅数据区时不会将第一条记录自动当成表头。复制、导出、写回只处理选区。
- 预览展示表头行号、字段路径和保留状态。保留字段可复制、导出；跳过项仍留空。
- 完整选中的标题/表头合并格可处理左上角文字，写回保留合并结构，支持撤销；合并范围改变后跳过。导出不复制格式或合并结构。

自动扫描首 80 个使用行、256 列，另读取正式 Excel 表头。未知字段或复杂布局可能无法可靠识别，请核对预览并手动指定；不保证所有报表均能自动判断。

验证：核心识别用例、真实 Excel 的选择/导出/写回/撤销、生产 Electron 界面以及现有回归套件。用户提供的余额表按只读方式验证，第 2 行 20 个字段被识别，名称数据表没有误判表头；验证前后源文件字节完全一致。样本及业务数据不随代码或安装包发布。

运行环境保持不变：Windows x64、.NET Framework 4.6.2+，包含 x86/x64 Excel XLL 和 Electron 44.7.0。实际 Excel 测试环境为 Windows 11 + Excel 16 x64；未在真实 Excel 2010/x86 环境完成安装验证。

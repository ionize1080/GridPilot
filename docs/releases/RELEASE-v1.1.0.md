# GridPilot v1.1.0

> 本页记录该次发布，保留原始功能与验证结论。[最新使用文档](../README.md) · [全部版本](README.md)

新增文件夹报表数据库，支持时点快照、累计记录归并、来源追踪、可视化筛选与可编辑的只读 SQL。源 Excel 保持唯一编辑入口；保存源表后手动扫描同步新增、修订和删除。

- **报表数据库**：多库独立配置；按内容哈希增量扫描；整次事务提交；日期、贷款号、组合键、金额精度可配置。空贷款号有金额的记录保留并标记；同键冲突可查看全部来源。支持 `.xlsx/.xlsm`，宏与外部链接不运行。
- **20,000 条预览**：脱敏按 100/200 条分页，搜索覆盖完整替换结果；分词预览上限增至 20,000，提供搜索和分页。数据库也分页浏览，数据导入和聚合不受 20,000 条预览上限限制。
- **脱敏复制**：预览中选择工作表与行范围，直接复制脱敏后的表格值到系统剪贴板；提供 HTML 表格和文本格式，保留文本编号，不执行公式。单次最多 20,000 行／100 万格／16 MB。仍需先确认预览与保留字段。
- **图标**：中英文分词、两种原样复制和文本/数值图标按真实字形轮廓居中，统一线宽、留白、三套配色及高分辨率降采样；新增数据库图标。
- **导航**：右键重命名、新增、隐藏/取消隐藏、复制名称、上移/下移、移到首尾；同工作簿拖放排序，显示插入线；F2 重命名、Alt+方向键排序。结构保护、只读、非法/重复名称和最后可见表均有检查。

## 下载

- `GridPilot-1.1.0-clean-win-x64.zip`：清洁版，仅运行所需文件。说明文档和独立许可文本移出解压目录；完整归属声明合并到程序资源，可在“设置 → 关于与许可”阅读。词典文本是运行数据，予以保留。
- `GridPilot-1.1.0-portable-win-x64.zip`：完整便携版，附使用说明、数据库规则和验证记录。
- `SHA256SUMS.txt`：下载校验值。

两个包均包含 x86/x64 XLL 和 Windows x64 Electron 44.7.0。**必须完整解压**；按 Excel 位数加载对应 XLL。升级前退出 Excel，保留原配置文件。数据库保存在 `%APPDATA%\GridPilot\Databases`，不在安装目录中。

## 数据规则

时点型按日期 + 贷款号 + 所选区分字段保存。累计型优先使用贷款号 + 业务流水号；没有流水号时请配置足够的组合键。未配置时按完整行内容及出现次数归并，标记待核对。空号记录不会因缺少贷款号而丢弃；冲突展示代表行并保留所有来源。详见仓库 `DATABASE.txt`。

## 验证与兼容

通过 C# 核心回归、新增 Excel COM 操作测试、数据库规则/回滚/超时测试，以及生产 Electron 界面的建库、20,101 条导入、分页、筛选/SQL、来源定位和真实系统剪贴板测试。测试和演示使用合成数据；用户报表没有进入仓库或发布包。完整记录见 `VALIDATION.txt`。

旧版聚焦的完整桌面回归在前台/计时器阶段超时，本次没有改动该实现；该套件未记为通过。新增功能已通过独立测试。

本机验证为 Windows 11 + Excel 16 x64。Win10 21H1 + Excel 2010 与 32 位 Excel 尚未实机验收；x86 核心构建/测试不能替代该组合的实际验收。旧 `.xls` 需先另存为 `.xlsx`。库结构第一版创建后固定，变更字段/键配置请新建库。

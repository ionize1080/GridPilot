# GridPilot v1.5.0

- 总设置新增功能开关；导航与聚焦常驻，其余工具按需开启，Ribbon 顺序固定。可独立关闭排序右键入口。
- 自定义排序：完整中文数字、大中小微、命名序列和正则组合；逐行规则优先、稳定排序、预览、原生整行移动与恢复原序。
- 原生单元格 / Excel 表格右键菜单集成，不弹出第二套菜单；筛选箭头下拉框保持原样。
- 导航增加名称升降序和自定义规则排序；保留隐藏状态，支持原地重命名和自定义悬停颜色。
- 补齐排序、监管核对和简易脱敏独立图标，16 个命令图案互不重复；三套配色和高 DPI 绘制。
- 移除卸载时的强制终结器等待；工具窗口使用非模态生命周期，避免关闭 Excel 时仍有未返回的窗口回调。

## 使用与验证

首次使用或升级后，在“设置 → 功能开关”开启需要的工具。既有布局、聚焦配色与其他配置保留。排序详细规则与边界见 SORTING.txt，验证记录见 VALIDATION.txt。

本机验证 Windows 11 / Excel 16 x64。提供 x86 / x64 XLL；Windows 10 / Excel 2010 与 32 位 Excel 尚未实机验收。

余额样本中的 ROUND / RANDBETWEEN 超出智能脱敏的公式验证范围，原样导出仍安全拒绝；简易脱敏会跳过公式。测试用静态副本单独验证全量导出，原文件不修改。不应将这种拒绝误认为原样公式已获支持。

完整包和清洁包均包含独立浏览器；必须完整解压后加载 XLL。

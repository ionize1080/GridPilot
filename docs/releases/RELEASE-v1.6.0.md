# GridPilot v1.6.0

新增最多 20 级联动排序及 Electron 排序工作区。先按部门，再在部门内按客户，最后在客户内按项目排序；每一级均可独立升降序。

- 原生值排序由 Excel 计算，保留数字、日期、数字文本、布尔值、错误和空白的语义，支持拼音/笔画及区分大小写。
- 每级均支持自然数字、中文数字、自定义命名序列、正则与组合规则，并可插入 Excel 自带及用户定义的序列。
- 最多 20,000 行完整分页预览、搜索、跳页、原始行号，支持恢复原序。保存上次成功的层级规则。
- 横向合并、不同高度跨行合并及相交合并可按完整记录排序；公式和格式随记录移动，数据右侧无需预留空列。
- “Excel 原生选项”保留颜色、图标、字体颜色和从左到右排序入口。这类操作由 Excel 自身处理，不使用本工作区的预览和撤销。
- 导航首行图标工具：一键升降序、高级排序、刷新、设置。单击导航、双击/F2 改名、点击别处或 Enter 提交、Esc 取消。支持 Space、Insert、Alt+上/下快捷键。
- 一键排序可设置 A–Z、自然数字或最近使用的自定义规则。
- 新配置默认显示排序、复制、重命名、转换、撤销和简易脱敏；已有配置保留用户选择。统一图标规范并验证 16 个图标互不重复。
- 根目录文档整理至 `docs/guides`、`docs/development`、`docs/releases`、`docs/validation` 和 `docs/licenses`。

本版修复真实测试发现的错误值被当成负整数、配置额外追加默认排序层级、合并单元格单击选区识别、Excel 自定义序列 SAFEARRAY 读取、改名提交后跳转被丢弃、隐藏表头表格排序被忽略、原生弹窗被预览遮挡等问题。

构建基线：.NET Framework 4.6.2，64 位 Windows 10/11；x86/x64 Excel 加载项与独立 x64 Electron 运行时。实机验证为 Windows 11 + Excel 16 x64，旧版 Office 与 x86 Excel 未在本机实机验收。

完整包附文档和许可，清洁包仅含运行文件，许可仍可在“关于与许可”读取。升级请退出 Excel，完整替换运行文件并保留两份 GridPilot JSON 配置；不能只更新 XLL。

详见 [验证记录](../v1.6/VALIDATION.md) 和 [排序说明](../guides/SORTING.txt)。

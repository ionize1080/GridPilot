# GridPilot v1.4.0 — 监管核对与变动报告

> 本页记录该次发布，保留原始功能与验证结论。[最新使用文档](../README.md) · [全部版本](README.md)

新增 **监管核对** 工作区，将两期余额、发放回收、专项表关联、指标筛选、明细追溯和报告草稿连接为可重复运行的流程。

- 五个视图：核对总览、数据来源、指标规则、明细追溯、报告草稿。暖白/陶土色界面，结果优先、分页搜索、窄屏布局。
- 自动识别标准余额底稿，预填四类来源和取数映射；识别草稿需复核后运行。可保存方案、替换下期文件。
- 支持多表组合键关联、可视化筛选、客户/项目/科目归集、财务多项加减汇总。
- 同时检查监管两期金额、监管差额、底层余额变动及发放减回收加调整；使用定点金额汇总。
- 分类迁入迁出单独提供证据。Top N 与其他净变动共同解释全部净变动，支持保存每指标文字模板和占位符，不虚构业务原因。
- 无关辅助列错误不阻断。缺键、重复键、关联冲突、缺失金额等列入异常；失败指标可跳过，部分结果明确标记。
- 原始文件/工作表/行号追溯，可定位 Excel。导出 Markdown 草稿、CSV 明细和包含规则快照/来源哈希的 JSON 底稿。

入口：**Excel → GridPilot → 监管核对**。使用说明见 `RECONCILIATION.txt`，精细设计见仓库 `docs/v1.4/DESIGN.md`。

验证：核对引擎场景、生产 Electron 交互、既有功能构建回归，以及脱敏底稿的真实只读读取和独立汇总。样本读取 10,496 条记录、785 个归集组合，识别 131 条异常，保留“部分结果”；原文件未修改。该验收不代表样本全部监管指标已核对通过。

边界：不自动解释任意自然语言/Excel 公式口径，不自动认定业务因果；复杂嵌套条件、比例指标、汇率换算需先准备可靠字段。输出为待复核草稿。读取已保存公式缓存；不执行宏、不刷新连接。

完整解压便携包，按 Excel 位数加载 XLL；Windows 64 位、.NET Framework 4.6.2+。继续携带 Chromium，终端用户无需安装 Node、Chrome 或 WebView2。本机验证 Windows 11 + Excel 16 x64；Windows 10 / Excel 2010 / 32 位 Excel 未实机验收。

脱敏底稿、业务明细和本地方案不包含在代码仓库或发布包中。清洁包许可在“设置 → 关于与许可”中查看。

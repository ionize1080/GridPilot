# GridPilot v1.0.0 — 智能前后缀与大表完整脱敏

> 本页记录该次发布，保留原始功能与验证结论。[最新使用文档](../README.md) · [全部版本](README.md)

脱敏新增按词频推断的前后缀、编号位数和人名模式，可以手动修改；相同关联字段跨表自动同步。编号可识别 HT-2026-000185 这样的结构，项目和企业名称不再统一添加“有限公司”。

移除原有 50 万／200 万格固定门槛，分块处理完整工作簿，支持 Excel 最远行列边界，跳过空白区域，显示真实有内容行列及分阶段进度。格式逐行合并以降低内存峰值。内存、公式验证和取消保护仍然生效，超出能力时停止，不交付截断结果。

- 修复身份公式漏脱敏、条件比较符漏改写、短词二次替换和假名碰撞。增加受限整列公式引用，保留空白格计算语义。
- 修复转换撤销错误目标、嵌套小计复制结果漂移。外部编辑使撤销失效；保留公式重算不一致时按策略停止或固定为源值。
- 修复样式结构属性污染、畸形千位分组异常、日期公式越界。含身份原文的自定义数字格式回退为 General。
- 修复设置连续保存丢失修改、取消另存为关闭预览、关闭窗口后排队请求仍执行。
- 分词使用可复用专业词前缀树，生成词时检查输出预算，增加长文本取消检查。
- 私有 Excel 导出使用后台 STA，提交前回到宿主复核源数据；导出期间源数据改变会拒绝交付。私有进程退出滞留时有有界清理兜底。
- 涟漪增加衰减波峰、波谷和曲面层次，覆盖行头、列头并传播至边界之外。动画期间按绘制耗时使用约 8／16／32 毫秒自适应间隔，结束后恢复低频检查；不是固定帧率保证。

## 下载与升级

完整解压 GridPilot-1.0.0-portable-win-x64.zip。包内含 x86／x64 XLL，按 **Excel 位数**选择；Chromium 要求 **64 位 Windows**。退出 Excel 后解压至新目录，可复制旧版 GridPilot.navigation.json 与 GridPilot.tools.json。不要同时加载两个版本，不能只复制 XLL。

## 验证与边界

本机使用 Windows 11、Excel 16.0 x64 build 20326。测试覆盖审阅回归、250 万格及最远单元格、连续 20 次导出、取消和源变化、格式保留、浏览器连续保存与取消保存、实际 XLL 与聚焦。详细结果见 [验证记录](https://github.com/ionize1080/GridPilot/blob/v1.0.0/VALIDATION.txt)与[逐项修复清单](https://github.com/ionize1080/GridPilot/blob/v1.0.0/docs/v1.0/REVIEW-RESOLUTION.md)。

Win10 21H1 + Excel 2010、32 位 Excel 尚未实机验收，附兼容性测试包供目标机验证。公式继续使用保守白名单，不支持的关系会停止导出。自动前后缀需检查是否含敏感信息；基础格式可保留，条件格式规则、图表、批注、宏、外链等不复制。映射仅在当前窗口有效，跨期加密映射字典未纳入本版。

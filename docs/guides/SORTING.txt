GridPilot 1.6.1 多级联动排序

入口：Ribbon → 多级排序，或 Excel 原生单元格/表格右键菜单。新配置默认开启常用工具，已有开关选择保留。
可单独关闭“在 Excel 原生右键菜单显示自定义排序”；Ribbon 入口继续保留。
右键入口属于单元格和 Excel 表格原生菜单，没有第二个弹出菜单。筛选箭头下拉菜单不作扩展。

快速开始：点击“插入示例工作簿”，再点“使用部门 → 客户 → 项目示例”，会生成部门升序、客户升序、项目降序三层规则。示例写入新工作簿，不覆盖当前数据。

每层可选择原生值、自然顺序、自定义序列/中文数字/正则，可独立升降序、上下移动优先级及删除。最多 20 层。原生值由 Excel 处理数字、日期、文本、布尔、错误和空白，另可选数字文本按数值、中文拼音/笔画及区分大小写。

自定义规则可折叠。下拉框可插入中文数字、大中小微、组合规则及 Excel 内置/用户序列。预览最多完整显示 20,000 行，每页 50/100/200 行，提供原始行号、搜索和跳页。超过上限会明确提示仅预览排序后前 20,000 行，实际仍处理全部选区。

操作：选择一个单元格自动扩展连续区域，多格选择按选区处理；在 Excel 表格/筛选区域中使用完整表范围，包含隐藏行。请确认界面显示的地址和表头选项，并包含整条记录的所有列。预览后应用，不自动保存。窗口“恢复原序”或 Ribbon“撤销上次操作”可撤销；后续内容或合并编辑会使旧预览/撤销失效。完成后可重新读取继续排序。

规则每行一条，优先匹配靠前的规则；从名称开头匹配，可用 .*? 匹配前缀。
例如：
(国际)[中文数字]
(业务)[中文数字]

国际二部 → 国际十一部 → 国际一百零一部 → 业务一部 → 业务十部。
降序只反转组内序列，规则优先级保持不变。相同键继续比较下一层；所有层相同才保留原序。未匹配项置后，仍参与后续层比较。
[大中小微][中文数字] 可以形成两层组合；大一、大十、中二、小一、微一。

自定义序列区每行“名称=项目1,项目2,项目3”，如：
级别=特大,大型,中型,小型,微型
阶段=准备,实施,验收
规则中用 [级别][中文数字] 或 [阶段]。项目作为文字匹配，不解释正则；较长项目优先匹配，排序仍按定义顺序。
规则中的其他部分是 .NET 正则，如 (国际|海外)[中文数字]、[A-Z][中文数字]。
每个序列标记必须参与匹配；可选分支应拆成多行规则。最多 32 条规则，每条 512 字符。匹配有超时保护。
中文数字为任意精度整数，支持十百千万亿兆京垓秭穰沟涧正载、财务大写和两/〇，不使用仅到一百的枚举表。连续数字写法如二〇二四也能排序。
名称自然排序忽略自定义规则，按中文区域文字和阿拉伯数字分段比较，表2排在表10之前。

导航首行箭头直接排序并切换下一次方向，高级排序图标打开预览工作区；作用于选中页面所属工作簿的全部标签，包括隐藏页与图表页，不受搜索过滤影响。隐藏/深度隐藏状态保留。结构受保护时拒绝操作。导航设置可选 A–Z、自然数字、最近使用的自定义规则及下一次方向。
导航单击跳转、双击/F2 原地改名、Enter 或点击别处（含列表空白及窗格背景）提交、Esc 取消。编辑框右键支持撤销、剪切、复制、粘贴、删除及全选；菜单关闭后继续编辑，Ctrl+V 同样可粘贴新名称。Space 跳转、Insert 新建、Alt+上/下移动。非法或重复名称提示。悬停提示可关闭。

合并：横向合并随行移动；跨行合并及互相交叠的块作为完整记录，以首行排序，块内不拆行。合并标题可以作为表头保留。若合并块跨越所选范围或表头边界，需要选中完整区域/调整表头，不会静默拆散数据。

边界：一次最多 200,000 条数据行、2,000,000 单元格。不要求相邻列留空，临时插入列会在完成或失败后移除；若 Excel 自身不允许插列（例如最后一列有内容），可使用“Excel 原生选项”。Excel 表格标题行保留，汇总行排除。数组/溢出公式、透视表、受保护或只读工作簿不强行改写。颜色、字体颜色、图标和从左到右排序从“Excel 原生选项”进入；原生对话框操作不使用 GridPilot 的预览或撤销，遵循 Excel 自身限制。

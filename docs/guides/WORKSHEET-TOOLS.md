# 导航、聚焦与常用工具

[文档首页](../README.md) · 适用 v1.9.1 · 2026-10-21

## 工作表导航

在 GridPilot 打开导航，按名称搜索当前或全部已打开工作簿。可切换正则、大小写和隐藏页显示；刷新使用按钮或 F5。不同 Excel 进程的工作簿不互通。

| 操作 | 结果 |
| --- | --- |
| 单击／Space | 跳转到工作表 |
| 双击／F2 | 原地编辑名称 |
| Enter／点击别处 | 提交改名 |
| Esc | 取消当前改名 |
| Insert | 在当前页后新建 |
| Alt+上／下 | 移动工作表 |
| 编辑框右键 | 标准撤销、剪切、复制、粘贴、删除与全选 |

非法或重复名称会提示。右键菜单关闭后继续编辑，Ctrl+V 可粘贴。导航首行箭头执行快速标签排序，图标表示下一次方向；高级排序打开预览工作区。排序针对选中页面所属工作簿的全部标签，包括隐藏页与图表页，不受搜索过滤影响；结构保护时拒绝。

[多级排序与规则](SORTING.md) · [导航外观设置](SETTINGS.md)

## 聚焦高亮

高亮活动单元格所在行／列，可留空中心，配合平滑移动与四向涟漪。效果由透明覆盖层显示，不改变工作表填充、边框、打印或文件内容，不截获鼠标。

在编辑、模态窗口、菜单等场景暂停；滚动和冻结窗格变化时跟随可见位置。动画和颜色设置见 [设置](SETTINGS.md)。高 DPI 与 Excel 2010 的实际体验需按 [目标机清单](COMPATIBILITY.md) 验收。

## 批量重命名

选择当前／全部工作簿范围，设置查找替换、正则、前后缀、空格、字母大小写或编号，先检查预览再应用。隐藏页、图表页与 31 字符截断可配置；名称冲突不会静默覆盖。

当次规则只有点击「保存为默认」才用于下次，不会自动保存工作簿。改名与内容转换使用 GridPilot 的撤销记录；后续编辑可能使记录失效，不能把它当作跨会话版本历史。

## 文本与数值转换

将选区常量转为文本或数字，可保留视觉位置、跳过隐藏单元格、保护前导零和长编号，控制千位符、百分比与分隔符。默认保护 15 位精度；已经被 Excel 丢失的编号精度无法恢复。

默认最多 50,000 个可转换常量，设置范围 100–200,000。大范围调用 Excel 仍可能暂时占用界面；绿色角标是否显示也取决于 Excel 错误检查设置。

## 各功能的恢复方式不同

| 功能 | 恢复／源保护 |
| --- | --- |
| AI 修改 | 最新恢复点前后切换 + 完整 Recovery 副本 |
| 多级排序 | 窗口「恢复原序」或 GridPilot 撤销，受后续编辑校验约束 |
| 改名／转换／简易脱敏写回 | GridPilot 当前会话撤销记录，后续编辑可能使其失效 |
| 原样复制／分词 | 输出新工作簿，源内容不写回 |
| 智能脱敏 | 另存新 XLSX；不是对源工作簿原地处理 |

先看对应功能的具体边界，再选择恢复方式。[AI 恢复](AI.md#批准与恢复) · [简易脱敏](SIMPLE-MASKING.md) · [原样复制](COPYING.md)

# 常见问题与处理

[文档首页](../README.md) · 适用 v1.9.1 · 2026-10-21

## 加载与窗口

| 现象 | 先检查什么 | 处理 |
| --- | --- | --- |
| 看不到 GridPilot 选项卡 | XLL 位数、Office 加载项状态、是否完整解压 | 按 [快速开始](QUICKSTART.md) 加载；运行包内环境检查 |
| 复杂窗口打不开 | Browser、App、Chatbox、DLL 是否齐全 | 关闭 Excel 后完整重新解压；不要混用新旧文件 |
| 某个工具不在 Ribbon | 功能开关 | 在「设置 → 功能开关」启用，保存后查看 |
| 侧栏出现黑边 | 实际版本、宿主缩放／DPI、是否加载旧目录 | v1.9 已处理窗口边缘，v1.9.1 加固切换；完全关闭 Excel 后确认新版路径，再切换模式验证 |
| 侧栏和独立窗口不能互切 | 是否已升级 v1.9.1、是否正在切换 | 等当前请求完成后再点击；仍失败时记录 Excel 版本、位数、窗口状态与复现步骤 |
| 修改设置重启后丢失 | 便携目录写权限、保存错误、多个 Excel 进程 | 使用可写目录并重新保存；多个进程最后保存者生效 |

Win10 / Excel 2010 32 位仍需实机验证，已有修复不等于该环境已验收。[目标机清单](COMPATIBILITY.md)

## AI 提问与应用

| 现象 | 原因与操作 |
| --- | --- |
| AI 只回复一个公式，没有待应用建议 | 聊天文字不会写入 Excel；明确要求“使用 Excel 工具生成建议”。公式工具必须以 = 开头 |
| 公式写进去却是文字 | 使用了写值工具；改用单格／批量公式工具，并确认函数适用于当前 Excel |
| 提示上下文过期 | 重新选择范围并发送问题，生成新建议；不要重复提交旧快照 |
| 模型只看到几行 | 初始上下文是样本；要求工具分页读取或全范围统计，必要时扩大范围后重新发送 |
| 大表发送前等待较久 | 本地 Excel 正在分块准备数据；查看格数进度，可取消并缩小范围。单个 COM 调用返回前取消可能延后 |
| 多条建议重叠 | v1.9.1 按生成顺序合并内容、按属性合并格式；检查目标，丢弃不需要的旧项再应用 |
| 整批拒绝写入 | 查看具体错误；常见原因是目标手工变化、保护、合并、表格、数组／溢出或不支持的公式。重新捕获不能替代解除业务约束 |
| 应用按钮显示处理中 | 等待写入与变更后备份完成；避免重复点击。完成状态以操作结果和工作簿为准 |
| 自动批准每轮都要开 | 选择「本工作簿 · 多轮对话有效」。助手／工作簿关闭后需要重新开启 |
| 换到另一工作簿没有自动批准 | 授权隔离是预期行为；在该工作簿明确开启。回到仍打开的原工作簿保留原授权 |
| 透视表失败 | 源范围必须含唯一非空标题，字段名准确，目标为新表，结果不超过 100,000 格 |
| 没有工具或模型不调用工具 | 检查提供方、模型工具调用能力和连接状态；首次工具发现需等待。别把普通回答当成执行结果 |

## 恢复与备份

“变更前／变更后”只对应最新恢复点。手工编辑相关区域或对象后，校验会阻止覆盖；不要通过删除用户编辑来强行绕过。

需要更早状态，或助手已经关闭：从工具菜单「打开完整备份」进入 `%LOCALAPPDATA%\GridPilot\Recovery`，按时间打开副本，核对后另存。新恢复点不会删除旧完整副本，但当前界面没有所有历史恢复点列表。

提示备份失败时检查目录权限、磁盘空间、工作簿格式与 Excel 当前状态；先解决备份问题，再重新生成建议。若提示回滚失败，保留现场并使用完整副本核对，不要把错误当作无修改完成。

## 本地工具

- **脱敏输出没有某些单元格**：简易脱敏会跳过公式、错误、保护等目标，导出时留空防止未脱敏原文泄露；在预览中查看原因。
- **原样复制公式变成值**：依赖范围不完整或不支持的公式会按设置转值；需要完整依赖时调整选区或选择停止策略。
- **数据库／核对结果不是刚改的值**：这些工具读取保存的公式缓存；在 Excel 完成计算并保存后重新扫描／核对。
- **数据库只显示 20,000 条**：这是浏览上限；筛选可查看其他记录，聚合查询处理所有命中数据。
- **排序颜色／图标没有 GridPilot 预览**：此类操作通过 Excel 原生对话框执行，不进入 GridPilot 预览或撤销。

提供问题报告时使用合成数据，附 GridPilot、Windows、Excel 版本与位数、操作步骤和提示；不要附密钥或完整个人配置。[数据与存储](DATA-AND-STORAGE.md)

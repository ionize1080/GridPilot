# 设置与偏好

[文档首页](../README.md) · 适用 v2.1.0 · 2026-10-22

从 Ribbon「设置」打开总设置，修改后点击「保存设置」。导航面板内仍有轻量布局设置，修改即时生效并合并保存。服务商、模型、密钥和聊天主题在 Chatbox 自身设置中管理。

## 功能开关与 AI

| 设置 | 当前行为 |
| --- | --- |
| 导航、聚焦、设置入口 | 始终可用 |
| 新配置默认工具 | 多级排序、复制内部公式／数值、批量重命名、文本／数值转换、撤销、简易脱敏 |
| AI 助手 | 默认开启，可单独关闭 |
| 其他工具 | 在功能开关按需启用；已有配置的选择保留 |
| 排序原生右键入口 | 默认开启，可单独关闭，不影响 Ribbon 入口 |
| 快照预算 | 默认 500 MB，最低 100 MB；超额自动清理最旧历史版本，保存设置后立即执行 |
| AI 新手入口 | 解释公式、生成内容、分析数据、手动公式草稿可分别隐藏 |
| AI 工作方式 | 设置默认侧栏／独立窗口；运行中的助手也可用标题栏小按钮切换 |
| 自动批准 | 点击助手输入栏的盾牌，阅读风险并二次确认开启；默认关闭，不是保存的永久配置 |

## 导航布局

| 项目 | 默认／范围 |
| --- | --- |
| 停靠 | 默认右侧，可选左侧；浮动、上下停靠不作为重启位置 |
| 宽度 | 默认 320，260–1600 WPF 逻辑像素；实际受 Office 可用空间约束 |
| 行高、间距、字号 | 36 / 2 / 13；范围分别 28–80、0–10、11–18 |
| 自动刷新 | 默认 2 秒，可关闭或设 1–10 秒；F5 可手动刷新 |
| 工作簿名 | 自动：当前工作簿范围不重复显示，跨工作簿显示；也可始终显示／隐藏 |
| 显示项 | 页序号、普通表类型、品牌栏、底部信息、快捷键提示、悬停提示 |
| 快速排序 | A–Z、自然数字或最近自定义规则，保存下一次方向 |
| 搜索偏好 | 范围、正则、大小写、隐藏页开关保存；搜索词和工作簿名不保存 |

双行结果保留最小高度。图表标记和隐藏状态始终显示；隐藏悬停提示不会隐藏错误信息。快捷键提示依赖底部信息区显示。

滑块与直接输入均可使用，Enter／失焦提交，Esc 撤销当前输入；无效值不覆盖原值，超范围整数限制到边界。宽度按宿主 DPI 换算，保存的仍是逻辑像素。

## 外观与聚焦

图标有青瓷、晴蓝、石墨配色。导航可选浅绿、浅灰、深色，并调整背景、控件底色、文字、辅助文字、强调色与悬停色。颜色支持 `#RRGGBB`、`#RGB` 或无井号十六进制；色盘即时反馈。Office 自身 Ribbon、任务窗格标题及边框不由导航配色控制。

聚焦可分别启用行／列、保留中心空白，透明度 5–60%，滚动补偿间隔 16–100ms（默认 33ms）。选择事件立即更新；忙碌、编辑、模态窗口等情况下按宿主状态隐藏或暂停。

平滑移动默认关闭，邻近选择约 120ms 过渡；快速移动、滚动、布局变化直接定位。高对比度、远程会话或系统关闭动画时不启用过渡。四向涟漪可开关，时长 120–600ms、宽度 12–100、强度 5–50。效果不写入单元格格式。

## 业务工具默认项

| 工具 | 可调整内容 |
| --- | --- |
| 文本／数值 | 保持视觉位置、仅可见单元格、前导零与 15 位精度保护、去空格、千位符、百分比、分隔符、绿色角标提示；默认最多 50,000 个常量，可设 100–200,000 |
| 批量重命名 | 当前／全部工作簿、隐藏／图表页、替换与正则、前后缀、大小写、截断与编号；当次规则需“保存为默认”才用于下次 |
| 原样复制 | 范围、外观、隐藏状态、批注、视图、条件格式、公式回退和上限；详见 [复制](COPYING.md) |
| 智能脱敏 | 基础排版保留、同步替换备注原文；详见 [脱敏](MASKING.md) |

## 保存、损坏与升级

导航写入 XLL 同目录 `GridPilot.navigation.json`，约 400ms 合并保存并在退出时补存；工具写入 `GridPilot.tools.json`。两者保留一个 `.bak`，使用便携目录而非静默改存其他位置。

目录只读或保存失败时显示提示，本次设置可能已生效但重启不保留；修复权限后再次保存。损坏配置回退默认，下一次保存将损坏原文保留在备份；未知新 schema 不覆盖原文件。多 Excel 进程共享配置时最后保存者生效，没有跨进程实时同步。

导航配置不存在时可从旧 `SheetPilot.settings.json` 迁移。内部 `SheetPilot` 名称是兼容保留，不代表产品未升级。[存储位置与升级](DATA-AND-STORAGE.md)

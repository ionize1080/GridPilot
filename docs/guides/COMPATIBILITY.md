# 兼容性与目标机验收

[文档首页](../README.md) · 适用 v2.1.0 · 2026-10-22

## 环境与证据分开看

| 项目 | 当前要求／状态 |
| --- | --- |
| 操作系统 | 64 位 Windows 10/11；随包运行时为 Windows x64 |
| Excel | Windows 桌面版；根据 Excel 位数选择 x86 / x64 XLL |
| .NET | .NET Framework 4.6.2+；4.8 可满足此运行要求 |
| 外部界面运行时 | 包内提供，不要求安装 Chrome、Node.js 或 WebView2 |
| 已实测主机 | Windows 11 + Excel 16 x64 |
| x86 测试 | x86 测试进程通过，连接的是本机 x64 Excel；不是 x86 Excel 宿主加载验收 |
| Win10 + Excel 2010 32 位 | 目标环境，尚无实机验收结论 |
| macOS、Excel 网页版、32 位 Windows | 不属于当前便携包运行范围 |

便携形式不绕过 Office 信任策略、文件阻止或企业执行限制。首次加载问题可运行包内只读检查：

```powershell
powershell -NoProfile -File .\Check-Environment.ps1
```

脚本只读取环境，不安装组件或修改策略；它不是功能验收。若无法自动找到 Excel，可传 `-ExcelPath` 指向实际 `EXCEL.EXE`。

## 目标机人工清单

在合成工作簿和完整便携目录上测试，记录版本、位数、DPI、操作结果和截图。

- [ ] 加载对应位数 XLL；Ribbon 出现，没有同时加载旧版。
- [ ] 冷启动直接打开导航色盘，不依赖先打开设置；完成、Esc、重开正常。
- [ ] 导航跨工作簿跳转后可立即键盘输入、滚动，F2 编辑和右键粘贴正常。
- [ ] AI 侧栏边缘无黑框，Office 原生 X 可用，内部重复窗口按钮隐藏。
- [ ] 侧栏 ↔ 独立窗口重复切换；包含最大化、最小化、跨工作簿、宿主缩放和高 DPI。
- [ ] 中文输入与草稿在切换中保留，工具菜单操作后和输入时关闭。
- [ ] 大范围捕获进度更新，取消有效；不能把本地格数当作网络上传百分比。
- [ ] 公式、二维值、格式、六类图表及原生透视表在目标版本执行并核对。
- [ ] 手动应用、工作簿／对话级自动批准、重叠建议、丢弃和失败反馈正确。
- [ ] 变更前／后恢复、手工冲突拒绝覆盖、完整备份打开、关闭重开授权失效。
- [ ] 多级排序、合并块、复制、脱敏导出、数据库和核对使用合成数据通过。
- [ ] 聚焦在冻结窗格、缩放和滚动下跟随；不会改变格式、打印或拦截鼠标。
- [ ] 关闭助手与 Excel 后无遗留界面；配置重启后保存，用户工作簿不被测试修改。

早期 Release 如包含兼容性测试包，它只证明该包执行过的用例，不能代替上述当前版本人工验收，也不能单独验证 Chromium 界面。当前实际证据见 [验证总览](../validation/README.md)。

## 已知能力边界

旧版 Excel 的函数集合与新版不同；AI 公式按宿主能力使用普通兼容公式。大范围操作受位数、内存和 COM 调用耗时影响，未承诺固定耗时。不同工具的处理／预览上限各自独立，详见对应指南，不要把 AI 捕获范围与排序、复制或数据库容量混为一谈。

# 数据、隐私与存储位置

[文档首页](../README.md) · 适用 v1.9.1 · 2026-10-21

## 哪些操作联网

| 功能 | 数据流 |
| --- | --- |
| 导航、聚焦、排序、复制、文本转换、分词、脱敏 | 本机 Excel 与本地组件处理，不需要模型服务 |
| 报表数据库、监管核对 | 读取用户指定的本地报表；保存本地库或用户主动导出的结果 |
| AI 助手 | 原生 Chatbox 客户端连接用户配置的服务，发送问题、上下文样本、工具返回结果和主动附件 |
| 源码准备与构建 | 下载固定依赖、运行时和上游包；属于开发流程，不是读取用户表格 |

AI 完整冻结快照留在本机，但模型可按工具调用读取其中更多内容，这些返回结果随对话发送到服务。Recovery 完整工作簿副本不会自动加入模型附件。选择「不附加」仅影响新消息的自动上下文；历史消息及主动附件需另行管理。

隐藏行列不代表排除分享；工作簿范围排除隐藏工作表，仍可含可见表中的隐藏行列。发送前根据数据范围和服务政策作出选择。

## 文件保存在哪里

| 数据 | 默认位置 | 生命周期／备份方法 |
| --- | --- | --- |
| 导航设置 | XLL 同目录 `GridPilot.navigation.json` 和 `.bak` | 升级时保留 |
| 工具设置 | XLL 同目录 `GridPilot.tools.json` 和 `.bak` | 升级时保留 |
| Chatbox 配置、对话与服务设置 | `%APPDATA%\GridPilot\Chatbox-1.20.3` | 独立于便携目录；关闭助手后备份，可能包含服务密钥 |
| AI 完整备份 | `%LOCALAPPDATA%\GridPilot\Recovery` | 按恢复周期保存；不自动清理，关闭助手后仍保留 |
| AI 冻结读取数据 | 系统 TEMP 下 `GridPilot-ai-*` 临时文件 | 正常释放时删除；不是供用户手动恢复的文件 |
| 本地工具界面临时配置 | 系统 TEMP 下 `GridPilot-ui-*` | 正常退出清理，异常退出可能残留 |
| 脱敏临时文件 | 当前用户本地 GridPilot Staging 目录 | 正常结束／失败清理，异常退出可能残留 |
| 报表数据库 | `%APPDATA%\GridPilot\Databases` | 关闭相关窗口后备份整个目录；每个库独立 SQLite 文件 |
| 脱敏结果、恢复 JSON、核对方案与结果 | 用户选择的位置 | 主动保存；恢复 JSON 含原始数据，方案可能含来源路径 |

备份和数据库不提供额外的内容加密承诺；使用适当的 Windows 权限和磁盘保护。Chatbox 的服务设置由其原生存储管理，不应将整个配置目录当作可公开分享的文件夹。

## 升级与清理

升级前关闭 Excel 和助手，备份便携目录及上述需要保留的用户数据。仅保留 JSON 配置，不混入旧 DLL、App 或 Chatbox 代码。发布包不包含开发者密钥、真实工作簿、个人聊天配置、数据库或 Recovery 文件。

清理 Recovery 前先打开需要保留的副本确认内容，关闭相关窗口后再手动整理。删除副本会失去对应完整文件恢复路径。清理聊天记录不等于删除数据库或 Recovery，反之亦然。

简易脱敏的还原 JSON 是包含原文的位置映射，不是加密文件。不要把它与脱敏后的共享报表一起发送。固定首字母／字符变换也不等于密码学匿名化。

## 分享问题报告

优先使用合成数据复现，描述 Windows、Excel 版本与位数、GridPilot 版本、操作步骤和实际提示。截图应遮盖业务内容、密钥、服务地址中的令牌及个人路径；不要提交整个 Chatbox 用户配置目录。开发测试的密钥处理方式见 [构建与测试](../development/BUILD.md)。

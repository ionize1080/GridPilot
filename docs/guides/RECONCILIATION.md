# 监管与财务核对

[文档首页](../README.md) · 适用 v1.9.1 · 2026-10-21

配置来源、期间和指标，比较差异并追溯到具体记录。

![两期核对总览，界面示意采于 v1.4](../v1.4/reconciliation.png)

*合成数据截图；两期核对总览，界面示意采于 v1.4，当前行为以下文为准。*

入口：Excel → GridPilot → 监管核对。

## 第一次使用

1. 数据来源 → 从余额底稿识别方案：识别“当期余额”“上期余额”“发放表YYYYMM”“回收表YYYYMM”。
   识别仅生成草稿，需要复核表头、业务组合键、金额单位和统计范围后勾选确认。
   其他布局通过“添加 Excel 来源”配置，支持 XLSX / XLSM。
2. 设置两期日期。季度请提供完整季度流水；余额为两个季末时点，不能跨月相加。
3. 指标规则中配置取数项：上期、当期，以及可选的发放、回收、调整。
   业务键通常为贷款号+币种；流水需要交易唯一编号等组合键。
   归集维度可选客户号、项目号、科目号等，所有取数项的维度顺序保持一致。
4. 按指标代码绑定监管报表的上期、当期和差值列。未绑定不会显示“监管一致”。
5. 用专项表关联带入分类字段；两期分别连接对应期间专项表。
6. 运行核对 → 查看差异及异常 → 点击指标 → 点击“几笔”查看明细并定位 Excel。
7. 指标规则可设置报告文字模板（{指标}、{当期}、{主要变动} 等占位符）；留空使用默认模板。
   报告草稿 → 补充业务原因 → 导出 Markdown / 明细 CSV / 完整底稿 JSON。
8. 保存方案；下期打开方案，更换来源文件、期间，重新核对。

## 财务 / 试算平衡

选择“财务 / 试算平衡多项汇总”，按科目设置多个取数项及加减方向。
例如净借方余额 = 借方金额加项 + 贷方金额减项。本类型不强制发放回收核对。

## 异常处理

无关辅助列的 Excel 错误不阻断；实际用到的金额、键或筛选字段错误会跳过该行，
并将整个指标标为“部分结果”。缺失来源、缺字段等仅跳过相关指标。
缺键或重复键不能默认当零或悄悄去重。手动跳过指标请填写原因。
未解释差额保留，不会自动归为“业务正常变动”。分类迁移证据不重复加入现金流。

读取已保存公式缓存；先在 Excel 计算并保存。宏与外部连接不会执行。
金额内部精度百万分之一元，先换算单位再舍入；只选折人民币等统一币种字段。
日期列不选时，使用者需保证输入范围完整。YYYYMM 月份不等于月末日期。
支持多个 AND 条件、单字段多值（| 分隔）；复杂公式、嵌套条件、比例指标需预处理。
自动文字说明数据变化，不能代替业务人员核实因果与监管口径。

CSV 以行类型区分维度汇总与来源明细；每组汇总仅一次，逐笔金额按角色加总。
JSON 金额是百万分之一元的整数字符串，并包含来源哈希、规则快照和全部异常。
方案包含本地文件路径，结果包含业务明细；均由使用者自行保存与管理。
目前无自动运行历史、自动复核审批、Word/XLSX 报告导出或自然语言规则解析。

文件边界：单工作表最多 256 列、200 万个读取单元格；工作簿展开体积最多 512 MB。
复杂指标多次关联大表会增加内存占用，建议分批核对。单方案最多 80 来源、500 指标。
来源文件内容变更后应重新运行；旧来源行号不保证对应新文件中的同一记录。

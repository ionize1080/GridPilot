GridPilot 1.1 报表数据库

开始使用
在 Excel 的 GridPilot 选项卡点击“报表数据库”。创建时选择一个只存放同类报表的文件夹；可选择递归扫描子文件夹。第一版读取 .xlsx/.xlsm，不执行宏、外部链接或公式计算。旧 .xls 请先另存 .xlsx。扫描前请在 Excel 完成计算并保存。
每个库有独立 UUID/SQLite 文件，保存在 %APPDATA%\GridPilot\Databases。升级加载项不会覆盖此目录。备份时先关闭所有 GridPilot 窗口，再复制整个 Databases 文件夹。

字段配置
选择样本工作表、表头行、贷款号字段、日期字段、金额字段和金额小数位。所有文件须保持相同的工作表名、表头和列顺序。贷款号作为文本保留前导零；Excel 本身已经丢失的数字精度无法恢复。标题行可位于表头之前；表头不得为空、重复或使用 __ 前缀。
时点型：按快照日期 + 贷款号 + 补充键识别。月份 YYYYMM 归到当月 1 日；同一贷款不同月份分别保留，不能把各月余额相加当成存量。一个贷款同月有多个机构/币种/账户时，须把相应字段加入补充键。
累计型：推荐贷款号 + 流水号。没有流水号时选择足够区分业务的日期、金额、业务类型等组合；不能仅凭贷款号把多次发放或回收合并。未选补充键时按完整行内容 + 同一文件内出现次数归并跨文件重复，标为 weak_key，仍需人工核对。
贷款号或补充键为空：保留金额和源行，标记 missing_loan/missing_key。不会把所有空贷款号合并成一条。同内容文件的副本按文件哈希和行号归并，但不同文件中无法确认身份的空号记录均保留。
日期可来自字段或文件名（YYYYMM、YYYYMMDD、YYYY-MM-DD 等）。日期字段优先，配置了字段后不以文件日期悄悄替代空值。支持 Excel 1900/1904 日期系统。

扫描与修订
手动“扫描更新”检查文件 SHA-256，只重新解析新增/变更文件；跳过 ~$ 锁文件和符号链接。删除或移动离开来源目录的文件会移除其贡献，其他文件仍贡献的记录保留。
一次扫描一个事务；读取失败、表头变化、无效日期/金额、取消、超时或扫描期间文件变化均回滚。完全没有报表的文件夹会保留旧库并报错，以防目录离线导致误清空。保留表头、清空数据行的有效文件可以同步为空。
同键的不同内容、或同一文件多次出现同一强键，标记冲突。data 展示修改时间较新的代表行（并列按路径/行号固定排序），所有来源原文仍保留在 provenance。不要在未核对冲突时把代表行当成最终权威值。
第一版只有源 Excel 可以增删改。结果的“打开 Excel”定位原文件/表/行；在 Excel 保存后再次扫描。无需在数据库重复录入。查询界面、SQL 和程序接口均不提供直接编辑记录。

查询
可视化条件使用 AND 连接。“生成 SQL”明确更新编辑器；自由修改语句后点“执行查询”。包含搜索对原文按文字搜索；大小比较转为数字。日期范围可直接编辑 SQL 比较 __date（ISO 日期）。
data：归并后的记录；latest：最新日期的快照；issues：空号、缺键、弱标识与冲突；provenance：全部贡献行；files：当前文件哈希与统计；scans：成功扫描历史。
原始列以原表头作为 SQL 列名；中文列名可用双引号。__key 为稳定业务键摘要，__file/__sheet/__row 定位源行，__sources 为贡献数，__conflict=1 为冲突，__quality 为身份质量，__date 为规范日期，__loan 为文本贷款号。
原始数据列保留源表示，金额附加 __amount_minor 精确整数列，单位由建库金额小数位决定（2 位时为分）。精确汇总使用 SUM(__amount_minor)，最后在展示时换算；对 Excel 数值单元格（含数值公式缓存），仅消除不超过两倍机器精度相对误差的二进制尾差；原始金额表示保留。文本金额和真正超出精度的金额仍拒绝。SQLite 整数溢出会报错；SQL 用户自行转 REAL 后的浮点结果不保证分级精度。

示例
SELECT "月份", COUNT(*) AS 记录数, SUM(__amount_minor) AS 金额合计_分
FROM data WHERE __conflict = 0 AND __quality = 'ok'
GROUP BY "月份" ORDER BY "月份";

SELECT * FROM provenance WHERE __key = '从查询结果复制的业务键摘要'
ORDER BY __file, __row;

边界
每个文件最多 256 列、200 万个单元格；解压内容总计最多 512 MB。一个目录最多 10000 个报表。单个库可以保存超过 20000 条；20,000 仅是查询浏览上限，可通过筛选查看其他记录，聚合查询覆盖全部命中数据。
数据库查询在独立子进程执行，SQL 只读连接 + query_only + SQLite authorizer 三重限制；禁止 ATTACH、写入、扩展、PRAGMA 和不受支持函数。每个 SQL 请求 15 秒超时；扫描 15 分钟上限，可手动取消。多窗口同时写同一库会显示占用错误，保留已提交数据。
来源工作表、表头和键配置创建后固定；改变结构请创建新库。库文件没有加密，请使用适当的 Windows 用户权限与磁盘保护。

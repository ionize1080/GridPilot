# 智能脱敏

[文档首页](../README.md) · 适用 v1.9.1 · 2026-10-21

智能脱敏适用于跨工作表一致替换身份字段并导出新 XLSX。它使用本地规则与启发式识别，不调用模型；处理选区固定变换时可使用 [简易脱敏](SIMPLE-MASKING.md)。

## 操作流程

```mermaid
flowchart LR
    A["读取工作簿"] --> B["识别表头与关联字段"]
    B --> C["人工复核规则"]
    C --> D["预览替换"]
    D --> E["生成新 XLSX"]
    E --> F["重算、重开与验证"]
```

1. 打开脱敏，读取源工作簿。检查标题、表头、数据起始行及字段分组。
2. 确认哪些是身份字段，哪些需要保留；金额、日期和分类处理均需主动选择。
3. 调整前缀、后缀、位数及自然人模式，同一关联域保持一致规则。
4. 检查预览后导出到新文件名；源工作簿不写回，已存在的目标文件不覆盖。

## 表头、映射与备注

表头推断检查前 40 个内容行及合并层次，只是建议，需要人工确认。前后缀推断每列分布抽样最多 2,000 个值；请复核标签前缀、机构后缀和编号年份段。占位符、无数据标记和合计文字不直接当作身份。

自然人模式生成短中文姓名；姓名允许 0–18 位数字，编号要求 1–18 位。分配会检查重复替换及原文片段，随机空间不足会要求增加位数或调整规则。

可选同步替换备注中的身份原文，会影响自由文本，应检查预览与保留字段。公式中的字符串改写较保守，还会检查分支和查找结果的一致性。

映射仅存在当前窗口，没有持久化的跨期加密映射库。

## 范围、进度与取消

没有固定 500,000／2,000,000 个内容单元格截断，按自适应块覆盖 Excel 范围并跳过空区；只有格式的单元格不计为内容。内存余量仍受检查，32 位宿主容量更低，支持最大坐标不意味着能把整张 Excel 网格装进内存。

预览展示 60 项变化，导出处理全部内容。扫描显示已处理数量，已知总量的阶段显示阶段百分比；取消或关闭阻止最终提交，正在进行的 Office COM 调用需要先返回。

源访问和最终验证在宿主线程；私有 Excel 在自己的 STA 线程重算验证。异常退出可能在 `%LOCALAPPDATA%\GridPilot\Staging` 留下临时文件。只清理本任务创建的私有 Excel，不终止用户现有进程。

## 公式支持边界

| 支持 | 不支持时的处理 |
| --- | --- |
| A1、有限区域及受限制整列、同表／跨表引用 | 外部链接、名称、结构化引用、整行、动态／数组公式拒绝 |
| 加减乘除、百分比、比较 | 拼接、乘方及未知函数拒绝 |
| IF、SUM、COUNT、AVERAGE、MIN、MAX、AND、OR、NOT | 不推测 UDF 或未知函数 |
| SUMIF(S)、COUNTIF(S)、精确 VLOOKUP／MATCH、INDEX | 通配符查找等超出支持集时拒绝 |

单个公式范围最多 8,000,000 格，另有计算量和深度预算。不支持的公式会失败，不截断结果冒充成功。身份类公式结果仍须正确映射；日期规则检查原值和偏移后值，包括 Excel 1900 虚构闰日。验证针对当前数据，不保证任意未来输入仍保持关系。

## 输出会保留什么

默认新配置保留基础排版，可关闭。保留字体、填充、边框、数字格式、行高列宽、隐藏行列和合并；不保留条件格式规则及动态效果、形状、批注、宏、外部链接、名称和连接。

样式传输不带源值或关系；敏感的自定义数字格式回退 General，但其他静态格式文本或主题元数据仍可能存在，共享前复核。输出工作表使用 Sheet1、Sheet2 等中性名称；隐藏源工作表会作为可见输出表供检查。

预览后源数据变化会拒绝导出。输出不是完整工作簿克隆，也不是自动判定“所有敏感信息已经清除”；检查保留字段、备注和样式中的文字后再分享。

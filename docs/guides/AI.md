# AI 助手：可检查、可批准、可恢复的 Excel 操作

[文档首页](../README.md) · 适用 v2.0.0 · 2026-10-22

AI 助手使用固定版本 Chatbox，通过本地 Excel MCP 操作当前绑定的工作簿。模型不能开启批准开关、批准自己的建议、运行 VBA 或执行任意系统命令。

## 选择范围，再提问

输入栏选择「选区／工作表／工作簿／不附加」。发送时生成冻结上下文，摘要最多含 120 个样例单元格；模型可分页读取全量数据或调用本地统计。不要把样本当成完整数据。「不附加」停止添加新上下文，已有对话数据仍在历史中。

大范围捕获显示本地准备进度并支持取消。原生 Excel 调用结束后才能响应取消。这不是网络上传进度。修改数据、切换工作簿或打开恢复副本后，请重新发送问题以绑定最新上下文。

## 可以让 AI 做什么

保留读取、查找、统计、结构检查和六种基础建议工具，新增 `excel_help` 与 `excel_operation`，共 12 个入口。模型按需查询具体操作参数，不在每轮附加整个能力目录。

| 能力 | 示例 |
| --- | --- |
| 工作簿与工作表 | 创建、打开本地文件、结构描述、导入导出、CSV、布局、保护、复制、重命名、删除 |
| 单元格与范围 | 值／公式读写、清空、插入删除、特殊粘贴、查找替换、合并、排序、去重、填充、格式、验证、条件格式、目标求解 |
| 原生图表 | Excel 2010 的 73 种类型；编辑轴、绘图区、系列、点、颜色、字体、标签、图例、趋势线、误差线；组合与次轴 |
| 原生透视表 | 行／列／筛选／值字段增减与重排、11 种汇总、项目／标签／数值／日期筛选、排序、分组、计算字段／项、显示值方式、布局、切片器；2013+ 日期时间线 |
| 其他对象 | 表格、定义名称、批注、图片、迷你图的增删查改 |
| VBA | 分页读取、新建／替换模块、删除标准或类模块；文档模块可清空但不能删除 |
| 已接入常用插件 | 批量改名及预览、自定义多级排序、工作表排序、转文本／数值、原样复制、离线分词、简易脱敏 |

原生对象操作受 Excel 自身限制：部分属性只适用特定图表、OLAP 透视表不具有所有普通透视表操作、公式直接依赖追踪存在跨表限制。完整参数及边界见 [MCP 说明](../development/MCP.md)。数据库、监管核对、智能关系脱敏等复杂工作流仍使用各自界面，没有统一接入本次 MCP。

公式以 `=` 开头，英文函数名、逗号参数；根据宿主版本选择函数。Excel 2010 没有 XLOOKUP、FILTER、LET。写值接口把前导 `=` 保留为文字，不执行公式。

## 批准与恢复

输入栏独立按钮直接切换批准模式，无需打开菜单：

- **盾牌／灰色：手动批准**。先检查建议，再点击「一键应用」或「应用此项」。
- **闪电／红色浅底：自动批准**。修改即时应用，变更前后保存快照。
- 更多设置中选择「本工作簿 · 多轮对话有效」或「仅本次对话」。默认手动批准；授权只保存在助手内存中，不转移给其他工作簿。
- 联网搜索已移至更多设置，保留 Chatbox 原有开关；它与 Excel MCP 的本地操作相互独立。

![独立批准开关](../v2.0/auto-approval.png)

### VBA 逐项审批

检测范围集中在网络／Shell／进程启动，以及用于隐藏目标的动态调用。普通单元格处理和本地文件操作不扩大列为危险能力；注释忽略。检测到风险时，即使自动批准已开启，也只生成待审建议，界面显示代码与原因，必须单独点击「手动批准 VBA」；普通「一键应用」跳过它。

这是一层静态审核门槛，不是 VBA 沙箱或对任意混淆代码的安全证明。工具只写入，不运行代码。访问 VBA 需用户已允许 Excel VBA 工程访问；工具不会改信任中心。宏必须保存在 xlsm、xlsb 或 xls，避免 xlsx 快照丢失代码。

### 多版本完整快照

更多设置 → **历史快照** → 选择版本 → **打开完整副本**。副本保留工作簿内容、格式、VBA、透视缓存、图表及被删除工作表，原工作簿和未保存编辑保持打开。可反复打开不同版本比较，确认后自行另存。恢复时不运行宏、不更新外部链接；恢复副本不继承自动批准。

每次高级修改前后保存完整逻辑版本；手动建议在执行前检查工作簿是否变化，冲突则停止整批。执行中出错可能留下部分修改，错误返回变更前快照编号与已完成项，使用历史快照恢复。不要仅凭模型回复“完成”判断结果，应检查工具的 `applied=true` 和工作簿。

基础建议仍保留最新「变更前／变更后」快速切换，合并重叠内容建议；高级操作采用完整历史副本。基础工具对表格、合并、数组目标和混合格式的限制不等于高级工具不支持这些区域，高级工具遵从原生 Excel 限制。

### 存储与性能

快照位于 `%LOCALAPPDATA%\GridPilot\Recovery\history-v2`。OOXML 按 ZIP 部件拆开，使用 256 KiB 内容寻址压缩块和不可变版本清单；相同块只存一次。恢复校验 SHA-256；损坏时拒绝打开不完整文件。旧备份仍保留。

xlsx、xlsm、xlsb、xls 均支持。Excel 的 SaveCopyAs 仍需完整序列化，不能承诺数据库级瞬时快照；大工作簿会有保存成本。内容去重不等于零增长，目前不自动清理历史。不要单独删除共享 blobs；关闭助手后备份／整体迁移整个历史目录。恢复副本另占一份普通工作簿空间。

## 侧栏与独立窗口

标题按钮或更多设置可切换模式，保留中文草稿。侧栏使用 Office 原生关闭按钮，内部重复窗口按钮隐藏。v2.0 校正客户区对齐并裁切残留边框；Windows 11 / Excel 16 已验收，Excel 2010 黑边尚待该版本实机复核。

## 数据边界

AI 请求会向你配置的模型服务发送所选上下文、工具结果和主动附件。完整历史快照不会自动发送。工作表文字视为数据，不可变成审批指令。Excel MCP 不提供网络导入、HTTP/SSE 服务、外部连接刷新或宏执行；Chatbox 自身联网搜索另行控制。

密钥由 Chatbox 本地配置管理，发布包不包含测试密钥。备份可能包含原始敏感数据，按原文件权限管理。
